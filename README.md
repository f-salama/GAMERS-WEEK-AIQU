## About GAMERS WEEK

GAMERS WEEK is Qatar University's gaming event, organised with the QU Esports Club. This year AIQU was invited to run its own booth, so we built a set of AI-themed games that anyone can play, gamers or not.

## About AIQU

AIQU is the AI Association at Qatar University. We bring students together to learn, build and show off AI projects, through workshops, competitions and events.

- **Mission:** make AI approachable and fun for every student, whatever their background.
- **What we do:** workshops, competitions, student-led projects and campus events.
- **Contact:** aiqu@qu.edu.qa
